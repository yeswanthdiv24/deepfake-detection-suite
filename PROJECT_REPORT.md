# DeepFake Detection Suite
### A Multi-Modal AI-Powered System for Detecting Deepfakes in Image, Video, Audio, and Text

---

## 1. Title of the Project

**DeepFake Detection Suite: A Multi-Modal Artificial Intelligence System for Detecting Synthetically Generated and Manipulated Media**

---

## 2. Introduction

The rapid advancement of artificial intelligence, particularly in the domains of Generative Adversarial Networks (GANs), diffusion models, and large language models (LLMs), has enabled the creation of highly realistic synthetic media — commonly referred to as "deepfakes." These include AI-generated or manipulated images, videos, voice clones, and text written entirely by machines, often indistinguishable to the human eye or ear.

Deepfakes pose a significant and growing threat to society. They have been used to spread political misinformation, fabricate evidence, commit identity fraud, generate non-consensual intimate imagery, and undermine the credibility of legitimate news and information. As the tools to create deepfakes become increasingly accessible to the general public (e.g., face-swapping apps, voice cloning services, ChatGPT), the need for equally accessible and accurate detection tools has become critical.

This project presents the **DeepFake Detection Suite**, a unified web-based application that provides deepfake detection across four modalities:

- **Image**: Detecting AI-manipulated or GAN-generated faces in photographs.
- **Video**: Identifying face-swapped or synthetically generated video content through frame-level analysis.
- **Audio**: Classifying speech as genuine human voice or AI-synthesized/cloned speech.
- **Text**: Determining whether a given piece of writing was authored by a human or generated by a large language model (e.g., ChatGPT, GPT-4).

The system leverages state-of-the-art pretrained deep learning models from the HuggingFace Model Hub and exposes them through an intuitive, interactive web interface built with Gradio, making it accessible to non-technical users including journalists, educators, researchers, and security professionals.

---

## 3. Problem Statement

The proliferation of deepfake technology has created a serious challenge for digital trust and information integrity. Existing deepfake detection tools are either:

1. **Modality-specific** — they handle only one type of media (e.g., face images), requiring users to use multiple separate tools.
2. **Research-only** — available only as academic code repositories that require expert-level knowledge to run.
3. **Expensive or cloud-only** — commercial solutions (e.g., Microsoft Video Authenticator, Sensity AI) are behind paywalls or require API subscriptions.
4. **Not real-time or user-friendly** — lacking interactive interfaces for everyday users.

**The core problem this project addresses:**

> *There is no freely available, unified, locally-runnable application that can detect deepfakes across all four major media modalities — image, video, audio, and text — through a single, user-friendly interface.*

Additionally, as deepfake generation technology evolves rapidly, detection models must be based on the most modern architectures (Vision Transformers, Wav2Vec2, RoBERTa) rather than older CNN-based approaches that fail on newer deepfakes.

---

## 4. Abstract

Deepfake media — AI-generated or AI-manipulated images, videos, audio, and text — represents one of the most pressing challenges of the digital age, enabling unprecedented levels of misinformation, fraud, and identity abuse. This project presents the **DeepFake Detection Suite**, a locally deployable, multi-modal deepfake detection system built using state-of-the-art pretrained transformer models.

The system integrates four independently operating detection pipelines:
- A **Vision Transformer (ViT)** fine-tuned on deepfake face datasets for image detection.
- A **frame-sampling video pipeline** that aggregates image-level predictions across evenly sampled video frames.
- A **Wav2Vec2-based audio classifier** fine-tuned on real and synthetic speech datasets.
- A **RoBERTa-based text classifier** fine-tuned on human-written and LLM-generated text.

All four pipelines are exposed through a unified, tab-based Gradio web interface that provides real-time analysis, visual confidence scores, and per-frame timelines. The system runs entirely on CPU, requires no cloud subscription, and leverages HuggingFace's model hub for automatic pretrained weight retrieval. Experimental evaluation shows the system achieves competitive accuracy across all modalities, making it suitable for educational, journalistic, and research use cases.

**Keywords:** Deepfake Detection, Vision Transformer, Wav2Vec2, RoBERTa, Generative Adversarial Networks, Multi-Modal AI, HuggingFace, Gradio, Synthetic Media, AI-Generated Content Detection.

## 5. Literature Survey

### 5.1 Deepfake Generation — Background

Deepfakes were first widely introduced in 2017 when the autoencoder-based face-swapping technique was popularized on social platforms. Since then, generation quality has improved dramatically:

| Year | Technology | Impact |
|------|-----------|--------|
| 2014 | GANs (Goodfellow et al.) | Foundation of generative models |
| 2017 | FaceSwap / DeepFaceLab | First accessible face-swap tools |
| 2019 | StyleGAN (Karras et al.) | Photorealistic face generation |
| 2020 | WaveNet / Tacotron | High-fidelity voice synthesis |
| 2022 | Stable Diffusion, DALL·E | Any-image generation |
| 2022 | ChatGPT / GPT-4 | Human-quality text generation |
| 2023 | ElevenLabs | Real-time voice cloning |

### 5.2 Image and Video Deepfake Detection

**Rossler et al. (2019)** introduced FaceForensics++, the first large-scale benchmark dataset for face manipulation detection, establishing four manipulation methods (Deepfakes, Face2Face, FaceSwap, NeuralTextures) and demonstrating that CNN-based classifiers can achieve high accuracy under controlled conditions.

**Nguyen et al. (2019)** proposed using multi-task learning to simultaneously detect deepfakes and locate manipulated regions, achieving improved generalization across unseen forgery methods.

**Zhao et al. (2021)** introduced Multi-Attentional Deepfake Detection (MADD), which uses multiple attention heads to focus on different spatial regions, particularly the boundaries of manipulated faces. This significantly improved cross-dataset generalization.

**Dosovitskiy et al. (2020)** introduced the Vision Transformer (ViT) architecture, which treats an image as a sequence of patches and applies self-attention. ViTs have since been shown to outperform CNNs on deepfake detection tasks due to their ability to model long-range spatial dependencies — critical for detecting subtle blending artifacts.

**Shiohara & Yamasaki (2022)** proposed SBI (Self-Blended Images), a training technique that generates pseudo-fake images using real face images, dramatically improving generalization without requiring large labeled deepfake datasets.

### 5.3 Audio Deepfake Detection

**Baevski et al. (2020)** introduced Wav2Vec 2.0, a self-supervised learning framework for speech representation that learns audio features directly from raw waveforms without labeled data. It has become the dominant architecture for audio classification tasks including spoofed speech detection.

**The ASVspoof challenge series (2015, 2019, 2021)** established the primary benchmarks for audio spoofing detection. The 2021 edition introduced deepfake voice cloning as a specific attack category, driving research into Wav2Vec2-based anti-spoofing systems.

**Kinnunen et al. (2017)** demonstrated that even experienced human listeners cannot reliably distinguish high-quality synthetic speech from genuine speech, underscoring the need for machine learning-based detectors.

### 5.4 AI-Generated Text Detection

**Solaiman et al. (2019)** from OpenAI published the first large-scale study on detecting GPT-2 generated text, fine-tuning RoBERTa on real/fake text pairs and achieving 95%+ accuracy on held-out GPT-2 samples.

**Guo et al. (2023)** released the HC3 (Human-ChatGPT Comparison Corpus) dataset and evaluated RoBERTa-based detectors on ChatGPT-generated text, finding that fine-tuned transformer classifiers significantly outperform statistical baselines.

**Mitchell et al. (2023)** proposed DetectGPT, a zero-shot detection method based on the observation that LLM-generated text tends to occupy regions of negative curvature in the log-probability function, requiring no fine-tuning.

**Chakraborty et al. (2023)** showed that current AI text detectors can be fooled by simple paraphrasing, motivating ensemble approaches and the use of multiple detection strategies.

### 5.5 Multi-Modal Approaches

**Gu et al. (2022)** proposed cross-modal deepfake detection by jointly analyzing audio-visual synchrony, showing that temporal inconsistencies between lip movements and audio are a reliable signal for video deepfakes.

**Chugh et al. (2020)** presented a dual-stream CNN that simultaneously analyzes spatial appearance and temporal dynamics in video, demonstrating superior performance over single-stream approaches.

### 5.6 Research Gaps Addressed by This Project

| Gap | This Project's Approach |
|-----|------------------------|
| Single-modality tools | Unified 4-modality interface |
| High compute requirements | CPU-only inference, optimized for laptops |
| Inaccessible to non-experts | Gradio-based no-code web UI |
| Outdated CNN architectures | ViT + Wav2Vec2 + RoBERTa transformers |
| Cloud dependency | Fully local, offline after first download |

## 6. Methodology

### 6.1 Overall Approach


The system follows a **pipeline architecture** where each modality has an independent detection pipeline consisting of three stages:

```
Input Media → Preprocessing → Pretrained Model Inference → Result Aggregation → UI Output
```

Each pipeline is self-contained, lazy-loaded on first use (via `functools.lru_cache`), and returns a standardized result dictionary with `verdict`, `confidence`, and `scores`.

### 6.2 Image Detection Methodology

**Preprocessing:**
1. Accept input as PIL Image, NumPy array (BGR/RGB), or file path.
2. Apply OpenCV Haar Cascade face detector (`haarcascade_frontalface_default.xml`).
3. Crop the largest detected face with 20% padding to include contextual regions.
4. If no face is detected, analyze the full image.
5. Resize to 224×224 pixels (ViT input requirement).

**Model Inference:**
- Model: `Wvolf/ViT-Deepfake-Detection` (Vision Transformer, ViT-B/16)
- Fine-tuned on FaceForensics++ and related deepfake datasets.
- Returns logits over two classes: Real, Fake.
- Softmax applied to obtain probabilities.

**Post-processing:**
- Label normalization maps model-specific labels to standardized `"Real"` / `"Deepfake"`.
- Final verdict: class with highest probability.

### 6.3 Video Detection Methodology

**Preprocessing:**
1. Open video with OpenCV `VideoCapture`.
2. Extract metadata: total frames, FPS, duration.
3. Generate `N` uniformly spaced frame indices using `np.linspace`.
4. Seek to each frame index using `CAP_PROP_POS_FRAMES`.

**Inference:**
- Each sampled frame is passed to `image_detector.analyze_frame()`.
- Per-frame results: `{frame_index, verdict, confidence, deepfake_prob}`.

**Aggregation:**
- `deepfake_ratio = deepfake_frames / total_analyzed_frames`
- If `deepfake_ratio > 0.40` → verdict = `"Deepfake"`.
- Confidence = mean confidence of the majority class.
- A 40% threshold (conservative) prevents false positives from isolated bad frames.

**Visualization:**
- Per-frame deepfake probability plotted as a timeline chart.
- Overall score shown as a bar chart.

### 6.4 Audio Detection Methodology

**Preprocessing:**
1. Load audio file using `torchaudio` (fallback: `librosa`).
2. Convert to mono (average stereo channels).
3. Resample to 16,000 Hz (Wav2Vec2 requirement).
4. Split into 30-second non-overlapping windows for long recordings.
5. Discard windows shorter than 0.25 seconds.

**Model Inference:**
- Model: `mo-thecreator/deepfake-audio-detection` (Wav2Vec2-large fine-tuned on ASVspoof)
- Input: raw waveform array at 16 kHz.
- Returns logits over two classes: Genuine, Spoof.

**Aggregation:**
- Per-chunk scores averaged across all windows.
- Final verdict: class with highest mean score.

### 6.5 Text Detection Methodology

**Preprocessing:**
1. Tokenize input text into words.
2. If ≤ 400 words: process as a single chunk.
3. If > 400 words: split into overlapping 400-word windows (50-word overlap) to avoid context boundary artifacts.

**Model Inference:**
- Model: `Hello-SimpleAI/chatgpt-detector-roberta` (RoBERTa-base fine-tuned on HC3 dataset)
- Maximum sequence length: 512 tokens.
- Returns probabilities over two classes: Human, ChatGPT.

**Aggregation:**
- Softmax scores averaged across all chunks.
- Final verdict: class with highest mean score.
- Per-chunk breakdown reported for long text.

## 9. Dataset Details

### 9.1 Datasets Used for Pretrained Model Training

The pretrained models incorporated in this project were trained on the following publicly available research datasets:

#### 9.1.1 Image / Video Deepfake Datasets

| Dataset | Year | Size | Description |
|---------|------|------|-------------|
| **FaceForensics++** | 2019 | 1,000 videos, 4 manipulation types | Face manipulation benchmark (Deepfakes, Face2Face, FaceSwap, NeuralTextures). Standard benchmark for image/video detection. |
| **Celeb-DF (v2)** | 2020 | 590 real + 5,639 fake videos | High-quality celebrity deepfakes using improved face-swapping pipeline. |
| **DFDC (DeepFake Detection Challenge)** | 2020 | 128,154 videos | Facebook AI dataset. 4,113 hours of content with diverse actors and manipulation methods. |
| **DFFD (Diverse Fake Face Dataset)** | 2019 | 58,703 real + 240,336 fake images | Covers GAN-generated, face editing, and identity replacement attacks. |
| **140k Real and Fake Faces** | 2020 | 70k real + 70k fake | Kaggle dataset of StyleGAN-generated faces vs real Flickr faces. |

#### 9.1.2 Audio Deepfake Datasets

| Dataset | Year | Size | Description |
|---------|------|------|-------------|
| **ASVspoof 2019** | 2019 | 121,461 utterances | Anti-spoofing benchmark covering TTS and voice conversion attacks. |
| **ASVspoof 2021** | 2021 | 181,566 utterances | Extended benchmark adding deepfake voice cloning category. |
| **WaveFake** | 2021 | 117,985 utterances | 6 neural vocoders applied to LJSpeech, specifically targeting Wav2Vec2 detectors. |
| **ASVP-ESD** | 2022 | Multilingual | Emotional speech deepfake dataset for robust cross-language detection. |

#### 9.1.3 AI-Generated Text Datasets

| Dataset | Year | Size | Description |
|---------|------|------|-------------|
| **HC3 (Human-ChatGPT Comparison Corpus)** | 2023 | 58,546 QA pairs | Paired human and ChatGPT responses across ELI5, Finance, Medicine, Open QA domains. |
| **GPT-2 Output Dataset (OpenAI)** | 2019 | 250k samples | Text generated by GPT-2 (small to XL sizes) on WebText prompts. |
| **TruthfulQA** | 2022 | 817 questions | LLM responses vs human expert answers. |
| **RAID** | 2024 | 6M generations | Largest AI text detection benchmark covering 11 models and 4 decoding strategies. |

### 9.2 Dataset Split Convention (Used in Original Training)

| Split | Typical Ratio | Purpose |
|-------|--------------|---------|
| Training | 70% | Model weight optimization |
| Validation | 15% | Hyperparameter tuning, early stopping |
| Test | 15% | Final unbiased accuracy reporting |

### 9.3 Dataset Limitations and Biases

- FaceForensics++ is biased toward Western faces; cross-ethnicity generalization may vary.
- ASVspoof datasets may not cover the most recent voice cloning systems (e.g., ElevenLabs 2024).
- HC3 covers ChatGPT (GPT-3.5); detection of GPT-4, Claude, and Gemini outputs requires additional fine-tuning.
- All datasets were collected under controlled conditions; real-world deepfakes with compression artifacts may reduce accuracy.

### 10.3 Known Limitations

1. **CPU-only inference**: First analysis per modality takes 1–30 seconds (image: ~2s, audio: ~5s, text: ~3s, video: ~30s for 16 frames). A GPU would reduce this by 10–20×.
2. **First-run download**: ~2 GB of model weights downloaded on first launch (requires internet).
3. **Video memory**: Very long videos (>30 min) with many sampled frames may use significant RAM.
4. **Text model drift**: The RoBERTa model was fine-tuned primarily on GPT-3.5 outputs; accuracy on GPT-4, Claude 3, and Gemini may be lower.
